# 💵 gmc_givebills

**運営がプレイヤーに「補填用のお金」や「マークされたお金」をアイテムとして渡せる、FiveM 用の管理者リソース**

</div>

GTA5 のロールプレイサーバー「GMC RP」の運営向けに作った FiveM のリソースです。
不具合などでプレイヤーが損をしたときの補填などを、管理者コマンド 1 つで行えます。

GMC RP は約 2 年間、日本トップの人気を誇ったサーバーです。
このリソースのほかに、ゲーム内スマホのアプリ「Style N&B」や、「新商品申請フォーム」などの Web アプリも作りました。

## 使い方

どちらのコマンドも管理者だけが使えます。

| コマンド | 渡すアイテム | 用途 |
| --- | --- | --- |
| `/givebills [ID] [金額]` | 補填用のお金 | 不具合などで損をしたプレイヤーへの補填 |
| `/giveblackmoney [ID] [金額]` | マークされたお金 | ゲーム内の犯罪系ロールプレイで使う、出どころの怪しいお金 |

- お金は現金として直接渡すのではなく、金額の情報を持ったアイテムとして渡します
- 渡した運営と、受け取ったプレイヤーの両方に通知が出ます
- 補填用のお金は、プレイヤーが使うとその金額が現金に変わります

## 工夫したところ

### お金を「アイテム」として渡す

現金を直接増やすのではなく、金額を持ったアイテムとして渡すことで、プレイヤーは好きなタイミングで現金に換えられます。
1 つのアイテムに金額を持たせるので、金額ごとに別のアイテムを用意する必要もありません。

### 現金化の記録を Discord に残す

補填用のお金を現金に換えると、金額とキャラクター名が Discord に自動で通知されます。
運営があとから「誰がいくら現金化したか」を確認でき、補填が正しく使われているかを見守れます。

### インベントリの違いに対応

アイテムの金額は、ox_inventory では `metadata`、従来の QBCore のインベントリでは `info` に入っています。
どちらのインベントリでも動くように、両方を確認して金額を読み取っています。

### 間違った入力を防ぐ

ID や金額が数字でないとき、金額が 0 以下のとき、指定したプレイヤーがいないときは、アイテムを渡さずにエラーを表示します。
